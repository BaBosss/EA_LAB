## มันทำอะไร / ไม่ทำอะไร

**ทำ:** รวมกำไร-ขาดทุนลอยตัวของ **magic 1524 ตัวเดียว** ข้ามทุกคู่เงิน → ถึงเพดานที่ตั้งไว้ (% ของ balance)
→ ปิดตะกร้าของมันทิ้ง → หลังจากนั้น**ไล่ปิดทุกไม้ที่มันเปิดใหม่**

🔴 **อ่านให้ชัด — มันไม่ได้ "ห้าม" NuiIndy เปิดไม้ ห้ามไม่ได้**
ไม่มี EA ตัวไหนห้าม EA อีกตัวเปิดออเดอร์ได้ กรงนี้ทำได้แค่ **เห็นทีหลังแล้วปิดตาม** (ช้าได้ถึง 5 วินาที)
กับ EA ที่เปิดใหม่ทันทีอย่าง NuiIndy มันจะกลายเป็นวงจร เปิด→ปิด→เปิด→ปิด **เสียสเปรดทุกรอบ และไม่จบเอง**
→ คอลัมน์ `reentries` มีไว้ให้เห็นวงจรนี้ **ถ้าเลขนี้เดิน = ต้องไปถอด NuiIndy ออกจากชาร์ตด้วยมือ**
กรงซื้อเวลาให้คุณ มันไม่ได้จบงานแทนคุณ

**ไม่ทำ:** ไม่เปิดออเดอร์เอง · ไม่แตะ magic อื่นแม้แต่ไม้เดียว (GoldReaper 8001-8015, MatchaGrid 20240001,
LondonConso 990005/99000512, BRK 991001/991002 ปลอดภัย) · **ไม่ได้ทำให้ NuiIndy ดีขึ้น** —
มันแค่เปลี่ยน "หางที่ไม่รู้ว่ายาวแค่ไหน" เป็น "ตัวเลขที่เราเลือกเอง"

**ทำไมต้องมี:** NuiIndy กินกำไรจากการทนไม้ลบ (escalation ไม่ใช่ signal) → `CutLoss_Percent=30` ของมันเอง
**ไม่เคยทำงานสักครั้ง** สวิตช์ที่ไม่เคยติด = สวิตช์ที่ไม่เคยถูกทดสอบ ⇒ บัญชีนี้ยังไม่มีเพดานจริง

## จะรู้ได้ยังไงว่ามันยังมีชีวิต

เขียนไฟล์ `EA_LAB_basketguard.csv` ลง `Terminal\Common\Files` ทุก 30 นาที (และทุกครั้งที่มีเหตุ)
คอลัมน์ที่ต้องดู:
- **`state`** — `ARMED` เฝ้าอยู่ · `HALTED` ตัดแล้วเกลี้ยง · 🔴 **`CUT_FAILED`** = **สั่งปิดแล้วปิดไม่ลง ไม้ยังค้างอยู่** (AutoTrading ปิด / ตลาดปิด / trade context ไม่ว่าง) เจอคำนี้เมื่อไร **บัญชียังไม่ถูกป้องกัน ต้องเข้าไปปิดมือเดี๋ยวนั้น**
- **`fires`** — จำนวนครั้งที่**ส่งคำสั่งปิดจริง** (โหมด DryRun เลขนี้ **ต้องเป็น 0 ตลอด** ถ้าไม่ใช่ = มีบั๊ก)
- **`would_fire`** — จำนวนครั้งที่ DryRun เจอว่าเกินเพดาน **นี่คือเลขที่คุณอยากดูตอนนี้** — มันบอกว่าถ้าเปิดโหมดจริงมันจะตัดไปแล้วกี่ครั้ง
- **`reentries`** — จำนวนครั้งที่ NuiIndy เปิดใหม่หลังโดนสั่งหยุด

> `fires=0` **ไม่ได้แปลว่าปลอดภัย** มันแปลว่า **ยังไม่เคยถูกทดสอบ** สองอย่างนี้คนละเรื่องกัน
> ถ้าอยากรู้ว่ามันตัดได้จริงไหม ต้องตั้งใจทดสอบ ไม่ใช่รอให้เกิดเอง
