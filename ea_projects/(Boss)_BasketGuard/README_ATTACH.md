## มันทำอะไร / ไม่ทำอะไร

**ทำ:** รวมกำไร-ขาดทุนลอยตัวของ **magic 1524 ตัวเดียว** ข้ามทุกคู่เงิน → ถึงเพดานที่ตั้งไว้ (% ของ balance)
→ ปิดตะกร้าของมันทิ้ง → **ล็อกไม่ให้เปิดใหม่** จนกว่าคนจะมาปลดเอง

**ไม่ทำ:** ไม่เปิดออเดอร์เอง · ไม่แตะ magic อื่นแม้แต่ไม้เดียว (GoldReaper 8001-8015, MatchaGrid 20240001,
LondonConso 990005/99000512, BRK 991001/991002 ปลอดภัย) · **ไม่ได้ทำให้ NuiIndy ดีขึ้น** —
มันแค่เปลี่ยน "หางที่ไม่รู้ว่ายาวแค่ไหน" เป็น "ตัวเลขที่เราเลือกเอง"

**ทำไมต้องมี:** NuiIndy กินกำไรจากการทนไม้ลบ (escalation ไม่ใช่ signal) → `CutLoss_Percent=30` ของมันเอง
**ไม่เคยทำงานสักครั้ง** สวิตช์ที่ไม่เคยติด = สวิตช์ที่ไม่เคยถูกทดสอบ ⇒ บัญชีนี้ยังไม่มีเพดานจริง

1. บัญชี **159475669** → เปิดชาร์ตอะไรก็ได้ 1 อัน (ตัวนี้ใช้ timer ไม่สนใจ symbol/TF ของชาร์ต)

3. ตั้งค่า:

| input | ค่า | หมายเหตุ |
|---|---|---|
| `InpMagic` | **1524** | ตัวเดียวที่มันแตะได้ · ใส่ 0 = EA ปฏิเสธการเริ่ม |
