# Negative Knowledge

Store **research-level** negative findings here: failed replications, contradictory claims, transfer failures, known caveats, or ideas that are not worth re-investigating without new evidence.

This directory is not QI Negative Experiment Memory. QI-1 defines that memory as a derived view of durable ExperimentResultV1 records with `REJECTED`, `INCONCLUSIVE`, or `INVALID` verdicts.

Before proposing a new experiment, query both:

1. this research-level negative knowledge; and
2. existing experiment/result/event evidence.

Never invent a historical verdict to make a duplicate idea look resolved.
