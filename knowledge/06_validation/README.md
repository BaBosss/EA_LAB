# Validation Knowledge

Research methodology for deciding what evidence a future controlled experiment should collect.

Topics include IS/OOS separation, walk-forward analysis, Monte Carlo/bootstrap, parameter stability, multiple testing/false discovery, survivorship bias, look-ahead/data leakage, sample adequacy, benchmark design, regime coverage, and replication.

This directory may inform an experiment hypothesis or test design. It does not define or change current Factory acceptance policy and does not implement QI-2 Evidence Intelligence.
