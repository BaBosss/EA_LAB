# Session and benchmark boundaries can create distinct microstructure regimes
Three sources point to time-local execution context rather than a universal intraday state:
- `RC-SSRN1843305-001`: urgency can make optimal orders more aggressive as a finite trading window closes in a continuous double auction model;
- `RC-SSRN3375564-001`: benchmark times can concentrate order flow while reducing price impact in the modeled FX setting;
- `RC-SSRN870608-001`: predictable market closures can alter information asymmetry and produce time-varying/U-shaped trading intensity.

## EA_LAB_INFERENCE
Session/open/close/fix windows should be representable as context features when a hypothesis has an execution or liquidity reason to use them. They are not automatically alpha signals.

Any transfer to XAU/FX/BTC MT5 requires target-broker evidence for spread, liquidity, volatility and fill behavior around the relevant clock window.
