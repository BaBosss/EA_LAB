# Learning-to-Rank for cross-sectional systematic portfolios

Primary reference: Poh, Lim, Zohren & Roberts, arXiv:2012.07149 (2020).

## SOURCE_CLAIM

The paper argues that cross-sectional systematic strategies depend critically on ranking assets before portfolio construction. Instead of ranking simple heuristic scores or sorted regression/classification outputs, it applies learning-to-rank methods that explicitly learn pairwise and listwise relationships across instruments.

Using cross-sectional momentum as the case study, the authors report that the learning-to-rank approaches improve ranking accuracy and deliver approximately threefold higher Sharpe ratios than the traditional approaches in their experiments.

## Method / context

- Market / asset: cross-sectional multi-asset setting.
- Strategy example: cross-sectional momentum.
- Method: pairwise/listwise learning-to-rank before portfolio construction.
- Dependency: simultaneous comparable observations across a frozen asset universe.

## Result

The source supports learning-to-rank as a portfolio ranking method worth testing when the task is genuinely cross-sectional. It does not establish that a ranking model transfers unchanged to retail FX/CFD symbols or to a single-asset EA.

## Limitations / caveats

- The reported performance is source-specific and should not be generalized as a universal Sharpe multiplier.
- A learning-to-rank model requires a properly defined universe, labels/target, rebalance cadence, portfolio construction and cost model.
- A generic symbol-fitness screen is not the same as a synchronized cross-sectional portfolio backtest.
- Model complexity introduces additional selection and overfit risk.

## EA_LAB_INFERENCE

This paper does **not** justify a new root hypothesis. EA_LAB already has `HYP-SB-002` for cross-sectional relative-strength rotation.

Learning-to-rank is a possible later child only after:
1. `HYP-SB-002` semantics are frozen;
2. a deterministic synchronized portfolio simulator exists;
3. a non-ML ranking baseline is tested;
4. cost/turnover and multiple-testing treatment are explicit.
