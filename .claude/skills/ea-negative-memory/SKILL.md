# EA Negative Memory

Before proposing another test:

1. search `knowledge/90_negative_knowledge/` for failed replications, transfer failures, contradictions, and parked ideas;
2. search the existing QI experiment/result/event owners for equivalent or near-equivalent historical work;
3. compare mechanism, strategy revision, symbol, timeframe, parameter scope, cost assumptions, and data window before declaring two tests equivalent;
4. return one of `REUSE_PRIOR_EVIDENCE`, `EXTEND_PRIOR_EVIDENCE`, `JUSTIFIED_RERUN`, or `NO_PRIOR_MATCH`, with exact pointers;
5. if evidence is incomplete or incompatible, state the missing dimension rather than inventing a historical verdict.

This skill never writes QI Negative Experiment Memory itself; QI-1 defines that as a derived view of durable experiment results.

Hard boundary: RESEARCH_ONLY. No Factory verdict, deployment, trading, risk/default, promotion, owner-attestation, or QI-2+ authority.
