#
# WHY THIS FILE EXISTS
#   run_guard_trigger_tests.ps1 PART 1 validated the declared $FAST_SUITES set AGAINST ITSELF:
#   `foreach ($s in $suites)`, where $suites IS $FAST_SUITES. So a run_* suite that nobody ever
#   classified was INVISIBLE to it -- not failing, not warning, simply not looked at. Measured at
#   canonical 649207d6: 69 tracked run_* files under scripts/_test/, 31 in $FAST_SUITES,
#   38 unclassified and unseen.
#
#   This file is the OTHER direction: every tracked scripts/_test/run_* file must appear here
#   exactly once, with a TIER and a REASON. PART 8 of run_guard_trigger_tests.ps1 enforces
#   that 1:1 mapping and PRINTS its scope counts.
#
# THIS FILE IS NOT A WIRING INSTRUCTION.
#   Classifying a suite here does NOT put it in the fast tier and does NOT spend the pinned
#   120.0s full-tier budget. EXEMPT-with-reason is a first-class, valid outcome. The point is
#   that a suite must be SEEN, not that it must be RUN in the hook.
#
# FORMAT  (ASCII only -- PS 5.1 reads scripts/data as ANSI, and a suite that runs inside the
#          pre-commit hook must never emit non-ASCII: UnicodeEncodeError is reported by the hook
#          as `exit -1 SUITE THREW`, which is a real prior incident in this repo)
#
#   <filename>|<TIER>|<reason>
#
#   filename  LITERAL file name only, no directory, NO WILDCARD. The no-wildcard rule is
#             load-bearing: it is what makes this a CLOSED set. A blanket row such as
#             `run_*.ps1|EXEMPT|...` cannot silence the check, because PART 8 requires one
#             literal row per real file and refuses any row whose name is not a tracked file.
#   TIER      one of:
#               FAST       must be a member of $FAST_SUITES in run_fast_cages.ps1 (checked
#                          both ways -- FAST here and not there, or there and not FAST here,
#                          both FAIL)
#               HARNESS    the tier runner itself, not a suite it can contain
#               SLOW       governed slow tier: measured cost makes it unsurvivable in a hook.
#                          The reason MUST carry the measured number.
#               NOT_WIRED  deliberately unwired with the disposition on record in
#                          PROJECT_STATE.md. The reason MUST name that record.
#               UNMEASURED honest state: never measured against the pinned full-tier budget,
#                          so no wiring decision can be made. Visible, not silent.
#   reason    non-empty, >= 20 chars, one line.
#
# TIERS ARE NOT RANKED AND `UNMEASURED` IS NOT A PARKING LOT WITH NO COST: PART 8 prints the
# per-tier counts on every run, so the size of the UNMEASURED column is a number somebody has
# to look at rather than an absence nobody can see.
