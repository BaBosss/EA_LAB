## Traps this chain paid for (the new ones)

- **A PowerShell rewrite adds a UTF-8 BOM**, and a BOM'd `.py` kills a whole suite as
  `exit -1 SUITE THREW` with the cause swallowed. `[System.IO.File]::WriteAllText` or strip it.
- **An equality test against a free-text field can essentially never fire.** The attack that
  exposed it read *"parked as a BUILD-ON until the optimize probe runs"* and walked straight past a
  check whose whole purpose is to keep verdicts out of that store. Word boundaries, plus a
  specificity case proving an innocent value still passes.
- **A checker that reads one input from a fixed mode while another is injected is mixed-vintage.**
  The mutation suite ran a worktree store against an indexed contract and every CONTROL went red.
- **A text search cannot tell "invoked" from "mentioned".** A derived assertion about which suite
  runs `run_schema_fixtures.py` answered *itself*, because the comment four lines above named the
  script while explaining the case. Search the executed array, not the file.
- **Adding a checker costs its transitive imports**: `run_guard_trigger_tests` PART 4b demanded
  `registry.py` **and** `snapshot_validator.py` for the new suite on its first run.
- **`gen_*` and `check_*` are not the same to the lint.** `run_guard_shape_lint` L0 refuses an
  undeclared `check_*.py`; it also refused a new schema read that carried no `# snapshot:`
  declaration, which is how the mixed-vintage bug above was found.
